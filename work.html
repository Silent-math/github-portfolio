Quantitative finance · Independent study

Information diffusion in financial markets

How firm-specific information enters US large-cap equity prices, measured around timestamped SEC filings.

Universe
66 large caps across 11 GICS sectors
Data
daily market data, 2015 to 2025
Events
SEC 8-K item 2.02 filings

Steps

  1. Estimated event-time abnormal returns with rolling factor models.
  2. Tested lagged peer propagation against permutation and matched non-event nulls.
  3. Estimated transfer-entropy networks, then applied factor and common-volatility controls.
  4. Scored a daily self-exciting extreme-event count model out of sample.
  5. Conditioned the post-event return distribution and evaluated tail calibration.

Scope

Daily bars place within-session price discovery outside the study's scope. Transfer entropy is used as a predictive measure. The fixed universe introduces survivorship bias.

Engineering thesis · UTFSM 2024

E-KAN thesis

Image classification under uncertainty, using evidential output layers over a frozen EfficientNet backbone and a Kolmogorov-Arnold transformer.

Model
EfficientNet + KAN + evidential head
Evaluation
accuracy, calibration, OOD detection, selective risk

Architecture

A frozen EfficientNet backbone provides the feature representation. A Kolmogorov-Arnold transformer sits on top of it, and the output layer produces Dempster-Shafer mass assignments over class subsets rather than a softmax distribution, so ignorance and conflict are represented explicitly.

Method

  1. Implemented the Dempster-Shafer combination rule and the evidential loss in PyTorch, with unit tests over the layers.
  2. Trained under distribution shift, where the source and target class distributions differ.
  3. Measured ignorance, conflict, calibration, and set-valued decisions alongside softmax and temperature-scaling baselines.
  4. Built a parameter-matched MLP versus KAN factorial study.
